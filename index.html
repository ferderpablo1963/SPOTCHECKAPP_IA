2. Plano táctil Lobby Bar

El archivo pinta inicialmente en azul las mesas encontradas. Después puedes corregir cualquier mesa libremente: blanca → roja → azul → blanca.

Gira el teléfono a horizontal para ver mejor el plano general.
Azul = Abierta en sistema y ocupada · OK
Roja = Ocupada sin abrir · Discrepante
Blanca = Libre
